# Rule-Based Inference Engine

An interactive propositional logic inference engine for computer and network fault diagnosis.

## Features
- Forward Chaining
- Backward Chaining
- Knowledge Base Explorer
- Interactive Knowledge Graph
- Step-by-step Proof Traces

## Technology Stack
- Python and FastAPI
- React and Vite
- JavaScript
- React Flow

## Run Backend
1. cd backend
2. pip install -r requirements.txt
3. uvicorn main:app --reload

## Run Frontend
1. cd frontend
2. npm install
3. npm run dev

## Domain
Computer and Network Fault Diagnosis.
